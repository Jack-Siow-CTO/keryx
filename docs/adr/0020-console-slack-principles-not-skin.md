# Console follows Slack interaction principles, not Slack visual cloning

Console copies Slack’s useful interaction patterns—dual-rail attention, Session-as-channel, conversation-first with secondary activity, sticky Approvals—but uses an original Keryx operator visual system (neutral chrome, system light/dark, single “needs you” accent). Layout is responsive: multi-column on wide desktop, stacked Inbox/Sessions navigation on mobile. Rejected: pixel-faithful Slack skin, IDE-only density, and consumer-chat simplicity that cannot surface Approvals and Run activity.
